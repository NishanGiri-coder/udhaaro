# Udhaaro

### Offline-first Kirana Credit Tracker 🇳🇵

Udhaaro is a Flutter-based Android application designed to help users manage grocery/Kirana credit, unpaid purchases, payments, and outstanding balances digitally.

## Features

* 🏪 Manage shops and shop details
* 🛒 Record grocery purchases
* 💰 Track outstanding credit
* 💳 Track payments and payment history
* 🔔 Outstanding amount threshold alerts
* ⏰ Scheduled unpaid-payment reminders
* 📄 Generate PDF statements
* 💾 Offline-first local data storage
* 🇳🇵 NPR currency support
* 📱 Clean and simple Material 3 interface

## Tech Stack

* **Flutter**
* **Dart**
* **Provider** — State management
* **Hive** — Local data storage
* **Flutter Local Notifications** — Notifications
* **PDF** — Statement generation

## Privacy

Udhaaro is designed as an offline-first application. User records are stored locally on the device and are not dependent on an online server.
